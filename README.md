# Task Manager

## What This App Does

Task Manager is a Flask-based web application for organizing work through tasks and projects. It gives users a simple interface for creating tasks, assigning priorities, tracking progress, grouping work into projects, and collaborating through comments.

The app is designed to help a user or small team keep track of work items from creation to completion.

## Core Purpose

The main purpose of this application is to provide a lightweight productivity system where users can:

- create and manage tasks
- organize tasks into projects
- assign priorities and statuses to tasks
- set due dates
- monitor overdue work
- comment on tasks
- track task-related activity
- view basic productivity statistics

## Main Features

### 1. User Authentication
The app includes authentication so users can log in and work with protected task data.

Authentication is handled by the backend route module `auth.py`.

### 2. Task Management
Users can create, update, view, filter, and delete tasks.

Each task can include:
- a title
- a description
- a status
- a priority
- a due date
- a project association
- a creator
- an assignee

These capabilities are centered around the Task model and the routes in `tasks.py`.

### 3. Project Organization
Tasks can be grouped into projects so related work is easier to manage.

Projects include:
- a name
- a description
- a color
- a collection of tasks

This functionality is handled by the Project model and `projects.py`.

### 4. Comments and Collaboration
Users can leave comments on tasks to discuss work, clarify requirements, or provide updates.

This is supported by the Comment model and the comments route module `comments.py`.

### 5. Activity Tracking
The application records task-related changes such as creation and updates.

This gives the system an audit trail that can be used to understand what changed and when. This is implemented through the ActivityLog model.

### 6. Statistics and Progress Monitoring
The app provides summary statistics for tasks, including:
- total number of tasks
- tasks by status
- tasks by priority
- overdue tasks
- completion rate

This reporting is generated by `get_stats()`.

## How the App Works

At a high level, the workflow looks like this:

1. A user opens the frontend in the browser.
2. The frontend sends requests to the Flask backend.
3. The backend routes process the request.
4. SQLAlchemy models read or write data in the SQLite database.
5. The backend returns JSON responses to the frontend.
6. The frontend updates what the user sees.

## Technical Overview

### Backend
The backend is built with Flask and organized using blueprints.

Key backend modules:
- `task-manager/run.py`
- `task-manager/app/__init__.py`
- `task-manager/app/models.py`
- `task-manager/app/routes/tasks.py`
- `task-manager/app/routes/projects.py`
- `task-manager/app/routes/comments.py`
- `task-manager/app/routes/auth.py`

### Frontend
The frontend is served from `task-manager/static/index.html`.

It acts as the user interface for interacting with the task and project APIs.

### Database
The app uses SQLite for storage and SQLAlchemy as the ORM.

The database is configured in `create_app()` with the URI `sqlite:///tasks.db`.

## Data Model Summary

### User
Represents an application user with login identity and ownership relationships.

Defined in `User`.

### Task
Represents a work item that moves through statuses such as todo, in progress, and done.

Defined in `Task`.

### Project
Represents a container for grouping related tasks.

Defined in `Project`.

### Comment
Represents user discussion attached to a task.

Defined in `Comment`.

### ActivityLog
Represents a record of changes made to tasks.

Defined in `ActivityLog`.

## Status and Priority System

The app uses predefined task states and priority levels.

### Status values
Defined in `VALID_STATUSES`:
- `todo`
- `in_progress`
- `done`

### Priority values
Defined in `VALID_PRIORITIES`:
- `low`
- `medium`
- `high`
- `urgent`

## Why This App Is Useful

This app is useful for:
- personal productivity tracking
- student project organization
- small team collaboration
- simple internal work management
- learning Flask CRUD architecture

It combines task tracking, project grouping, collaboration, and reporting in one lightweight application.

## Summary

Task Manager is a small but complete work-tracking application. It allows authenticated users to manage tasks, organize them into projects, collaborate through comments, and monitor progress using built-in reporting. The overall design is simple, making it a solid foundation for future features such as notifications, kanban boards, subtasks, or team workspaces.
